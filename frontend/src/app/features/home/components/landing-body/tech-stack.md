# Stack Tecnológico - Frontend Market Alerts App

## 🚀 **Framework Principal**
### **Angular 20.1.0**
- **Versión moderna** con standalone components
- **TypeScript 5.8.2** para tipado fuerte
- **Zone.js** para gestión de cambios asíncronos
- **RxJS 7.8.0** para programación reactiva

---

## 🎨 **UI Framework & Componentes**
### **Angular Material 20.1.5**
- **Design System** completo de Google
- **Componentes pre-construidos** y accesibles
- **Tema oscuro personalizado** con CSS variables

**Módulos Material utilizados:**
- 📱 **MatButtonModule** - Botones interactivos

- 📝 **MatFormFieldModule** - Formularios
- 🎯 **MatInputModule** - Campos de entrada
- 📋 **MatTabsModule** - Navegación por tabs
- 💬 **MatDialogModule** - Modales y popups
- 🎨 **MatIconModule** - Iconos vectoriales
- 📊 **MatToolbarModule** - Barras de herramientas
- 🗂️ **MatSidenavModule** - Menús laterales
- 🏷️ **MatBadgeModule** - Notificaciones y badges
- ✅ **MatCheckboxModule** - Casillas de verificación
- 🔄 **MatSlideToggleModule** - Switches
- 📎 **MatChipsModule** - Tags y chips
- 📜 **MatDividerModule** - Separadores visuales
- 🎭 **MatTooltipModule** - Tooltips informativos
- 📋 **MatListModule** - Listas de elementos
- 🍽️ **MatMenuModule** - Menús desplegables
- 🔔 **MatSnackBarModule** - Notificaciones temporales

- 📊 **MatSelectModule** - Selectores desplegables

## 📱 **Arquitectura Moderna**
### **Standalone Components**
- **No NgModule** necesario para componentes simples
- **Imports directos** en componentes
- **Mejor performance** y tree-shaking
- **Código más limpio** y mantenible

### **Feature Modules**
- **Modularización por funcionalidad**:
  - 🏠 `home/` - Landing y páginas públicas
  - 🔐 `auth/` - Autenticación y usuarios
  - 📊 `dashboard/` - Panel principal
  - 📈 `market/` - Análisis de mercado
  - 💼 `portfolio/` - Gestión de inversiones
  - 🔔 `alerts/` - Sistema de alertas
  - 👀 `watchlist/` - Listas de seguimiento
  - ⚙️ `settings/` - Configuración
