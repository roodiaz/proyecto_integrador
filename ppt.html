Cierre del proyecto

Conclusiones y trabajo a futuro

Conclusiones

  • Integración completa: frontend, API REST, procesos en segundo plano, dos motores de base de datos e integraciones externas funcionando de forma coordinada, no como módulos aislados.
  • Conocimientos aplicados: arquitectura en capas, modelado relacional y no relacional, autenticación con JWT, consumo de APIs externas y despliegue en infraestructura propia con contenedores.
  • Valor para el usuario: el saldo virtual permite operar con datos de mercado reales y practicar la gestión de un portfolio sin exponer capital propio.
  • Base extensible: el desacople mediante interfaces (proveedores de datos, envío de correo) permite incorporar nuevos servicios sin modificar la lógica central del sistema.

Trabajo a futuro

  • Incorporación de criptoactivos como nueva clase de instrumento
  • Soporte multi-moneda (USD, ARS, EUR)
  • Exportación del portfolio a CSV / Excel
  • Ampliación de las métricas de análisis financiero
  • Caché distribuida con Redis para mejorar la escalabilidad
  • Aplicación móvil nativa
